# separately without this restriction." The orders below are taken from chapter 6;
# the EXPECT lines encode the outcome the DATC text describes, using the author's
# stated preference wherever the DATC offers a choice of rule interpretations.

# These cases are written for the classic board, which this repository does not
# contain (see DECISIONS.md). The test runner loads that board's connection data
# from third_party/ after you run scripts/fetch-reference-maps.sh.

# Format
#   CASE <id> <title>
#   SETUP    extra units ("Power: F Place") and centre ownership ("own Power: a, b")
#   MOVE     movement orders; units named in orders are placed automatically
#   RETREAT  retreat orders for the units just dislodged
#   ADJUST   build / remove orders (board is put in the adjustment phase)
#   EXPECT   moved: / dislodged:   exact sets, by the province the unit started in
#            can-retreat: / cannot-retreat:   unit > destination
#            has: Power A place     units: exact list of every unit on the board
